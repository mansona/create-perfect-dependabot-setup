# create-perfect-dependabot-setup

This is a simple tool to update your `.github/dependabot.yml` to be **perfect** 😍

To run just copy the following: 

```bash
pnpm create perfect-dependabot-setup@latest
```

Note: this is still in progress so I will be tweaking it over the coming weeks/months. If you are trying it and you don't think the setup is perfect then feel free to [open an issue](https://github.com/mansona/create-perfect-dependabot-setup/issues/new/choose)
